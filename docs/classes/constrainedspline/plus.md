#  plus

Add a scalar offset to a spline output.


---

```matlab
 f = plus(f,g)
```
## Parameters
+ `f`  BSpline instance or scalar
+ `g`  scalar or BSpline instance

## Returns
+ `f`  transformed BSpline or empty when adding []
