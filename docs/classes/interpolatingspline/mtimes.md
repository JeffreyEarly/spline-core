#  mtimes

Multiply a spline output by a scalar.


---

## Declaration
```matlab
 f = mtimes(f,g)
```
## Parameters
+ `f`  BSpline instance or scalar
+ `g`  scalar or BSpline instance

## Returns
+ `f`  transformed BSpline or empty when multiplying by []
