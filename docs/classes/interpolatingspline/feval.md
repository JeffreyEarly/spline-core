#  feval

Evaluate a B-spline at the supplied points.


---

## Declaration
```matlab
 values = feval(spline,x)
```
## Parameters
+ `spline`  BSpline instance
+ `x`  evaluation points

## Returns
+ `values`  spline values with the same shape as x
